# About This Project

This repository is an outline of a setting for a high fantasy RPG.
The fundamental idea is to have fairly stereotypical fantasy species—humans, elves, and dwarfs—but to make them significantly different from one another in important ways, while preserving and explaining many of their sterotypical traits.
The core idea behind this is to give them very different relationships to mana, and thus magic, in ways which impact even their daily lives.
The setting would almost certainly require a custom ruleset, not just a hack of an existing set of rules.
